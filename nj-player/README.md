# NJ Player

An offline desktop video player for your downloaded videos, with a **"better Lucid Mode"** — real-time, GPU-accelerated video enhancement that goes beyond Opera's one-click sharpener.

- **Local files play fully offline** — no internet needed for downloaded videos (web links need internet, see below)
- **No AI** — pure GPU shader algorithms, fast and artifact-light
- **GPU-accelerated** — enhancement applies in real time as the video plays
- **Plays almost everything** — MP4, MKV, AVI, WebM, MOV and more (built on mpv)

---

## Quick start

1. Open this folder in PowerShell and run:

   ```powershell
   powershell -ExecutionPolicy Bypass -File install.ps1
   ```

   This downloads a portable mpv build and the enhancement shaders **into this folder** (nothing is installed system-wide, no admin needed). A small window may flash during install.

2. **Play a video** — two ways:
   - **GUI (easiest):** double-click `NJ-Player-GUI.bat` — it lists your videos, you pick an enhancement preset and hit PLAY.
   - **Drag & drop:** drag a video file onto `NJ-Player.bat` (or double-click it, then drop files onto the mpv window).

3. **Enhance** — press `F9` to cycle enhancement presets, or `CTRL+1..3` to jump straight to one. The current mode shows in the corner of the screen.

## Enhancement presets

| Key | Preset | What it does |
|-----|--------|--------------|
| `CTRL+0` | **Off** | Clean, unmodified playback |
| `CTRL+1` | **Lucid** | Smart adaptive sharpening — the Opera Lucid Mode look, without the over-sharpening artifacts |
| `CTRL+2` | **Cinema** | Full pipeline for low-res video: KrigBilateral (better color) → FSRCNNX x2 (upscale) → SSimSuperRes (de-ring) → adaptive sharpen |
| `CTRL+3` | **Anime** | Anime4K — restores line art and removes compression artifacts (also helps on cartoons/2D content) |

`F9` cycles through all four.

## Right-click "Open with NJ Player" (Windows)

Run once to add **"Open with NJ Player"** to the right-click menu of every file — right-click any video (or audio) and open it straight into NJ Player:

```powershell
powershell -ExecutionPolicy Bypass -File associate.ps1
```

What it registers (per-user, in `HKCU\Software\Classes` — **no admin needed, nothing outside your own user account**):

- **Right-click menu item** on every file → plays the file directly in NJ Player
- **Right-click "Clear NJ Player History"** → wipes resume positions and the remembered folder without opening the GUI (runs `clear-history.ps1`, asks first)
- **"Open with" dialog** entry for all 14 supported video types
- A proper app identity with the mpv icon

To remove it again: `powershell -ExecutionPolicy Bypass -File associate.ps1 -Remove`

If the menu item doesn't appear immediately, restart File Explorer (or just log out/in). If you ever **move the nj-player folder**, re-run the script so the registered path updates.

Note: this sets the *right-click* action. The default double-click player for videos is controlled by Windows (Settings → Apps → Default apps) — choose "NJ Player" there if you want double-clicking to open NJ Player too.

## Desktop icon

Run once to put an **NJ Player** icon on your Desktop (launches the GUI). It uses NJ Player's own logo (`nj-player.ico` — a dark tile with a cyan play button and "NJ"), falling back to the mpv icon if the logo is missing:

```powershell
powershell -ExecutionPolicy Bypass -File desktop-shortcut.ps1
```

Remove it with `-Remove`. If you move the `nj-player` folder, re-run it so the shortcut points at the new location.

The logo is generated by `make-icon.ps1` (pure PowerShell, draws it at 7 sizes and packs them into `nj-player.ico`) — run it again if you ever want to tweak the colors or design.

## Playing links from the web (YouTube, Twitch, live streams)

NJ Player can also play web links. In the GUI, paste a link into the **Link** bar (bottom) and hit **Play Link** (or press Enter). It accepts:

- **YouTube / Twitch / Vimeo / hundreds of sites** — powered by **yt-dlp**, which `install.ps1` places next to mpv
- **Direct video files** — `https://example.com/video.mp4`
- **Live streams / HLS** — `https://example.com/stream.m3u8`

This needs internet, of course — downloaded videos still play fully offline. NJ Player prefers H.264/MP4 streams by default (hardware-decodable on almost any GPU); to allow 4K+ or best quality, change `ytdl-format` in `mpv.conf` to `bestvideo+bestaudio/best`.

You can also play links without the GUI — from a terminal run `NJ-Player.bat "https://..."` and the link opens in NJ Player.

## Saving a web stream for offline (the Library)

The **Library** (`library/` folder, button at the top of the GUI) is where NJ Player keeps downloaded videos. To save a link so it plays later with no internet:

1. Paste the link in the GUI's Link bar (same one used for Play Link)
2. Click **Download** — NJ Player downloads it as an MP4 into the Library
3. The status line shows progress; when it's done, the video appears in the Library (the list refreshes automatically)

Downloads are **Full HD 1080p H.264 MP4s** — NJ Player picks the best H.264 video stream up to 1080p plus its audio and merges them into one MP4 (using the bundled ffmpeg), so files play on any machine and the enhancement presets apply exactly like local files. **Playlist links work too** — paste a YouTube playlist URL and all videos are downloaded as individual MP4s. One download at a time.

## Launcher GUI (`NJ-Player-GUI.bat`)

A small window that scans a folder for your videos and plays them with one click:

- **Quick-folder buttons** — one click jumps to Downloads, Videos, Desktop, or the **Library**
- **Frame preview** — select any video and a thumbnail from a few seconds in appears instantly (generated by mpv itself, cached so re-selecting is instant; the cache auto-trims at 200 files)
- **Download button** — save any web link as an MP4 into the Library for offline watching
- **Clear History button** — wipes resume positions (videos start from the beginning again) and the remembered last folder, with a confirmation prompt
- **Scans your Downloads folder by default** — "Include subfolders" is on, so videos inside subfolders show up too (paths are shown relative to the chosen folder)
- **Browse...** to point it at any folder (it remembers your last folder)
- **Enhancement dropdown** — Off / Lucid / Cinema / Anime4K, Cinema is the default
- **PLAY** or double-click a video to launch NJ Player with the chosen preset
- **Add to Queue** — queue up multiple videos to play in sequence
- **Queue panel** — see all queued videos, remove/clear/play them
- Status line tells you what's playing and with which preset

It's pure Windows PowerShell (WinForms) — no extra installs, works offline. The window can stay open while videos play; close it anytime.

## Playlist queue

Queue up multiple videos to play in sequence without stopping between each one:

1. Select a video in the list
2. Click **Add to Queue** — the video appears in the Queue panel below
3. Add as many videos as you like (from any folder)
4. Click **Play Queue** to play them all in order
5. Use **Remove** or **Clear** to manage the queue

mpv plays the queue as a playlist — you get seek-next/previous controls and can jump between videos.

## History & privacy

NJ Player keeps a small history so it can **resume videos where you left off** (`save-position-on-quit`). It's stored in `watch_later/` inside this folder — plus one system copy in `%LOCALAPPDATA%\mpv\watch_later` from before the redirect. The GUI also remembers your last browsed folder (`.last-folder.txt`).

To wipe all of it: GUI → **Clear History** button (it asks first), or right-click any file → **Clear NJ Player History** (no need to open the GUI). Both remove resume positions and the remembered folder — your Library downloads, thumbnails, and settings are kept.

**Per-video:** press **`CTRL+BACKSPACE`** while watching to clear just that video's resume position — next time it starts from the beginning, and quitting won't write a new position for it (other videos keep their history). Handy after you've re-watched something to the end or want a fresh start on one file.

## All hotkeys

| Key | Action |
|-----|--------|
| `F9` | Cycle enhancement presets |
| `CTRL+0` / `1` / `2` / `3` | Pick preset: Off / Lucid / Cinema / Anime |
| `CTRL+d` | Toggle debanding (removes color banding in dark scenes) |
| `CTRL+SHIFT+1` | Toggle the sharpening shader on top of the current preset |
| `CTRL+h` | Cycle hardware decoding (try if video stutters) |
| `CTRL+BACKSPACE` | Clear the resume position of just the current video |
| `TAB` then `2` | Show tech stats — you can see the active shader passes listed |

Plus all the standard mpv controls: `space` play/pause, `←`/`→` seek 5s, `↑`/`↓` seek 60s, `[`/`]` speed, `f` fullscreen, `m` mute, `s` screenshot.

## Where does everything live?

```
nj-player/
├── NJ-Player-GUI.bat  <- launcher GUI (double-click me)
├── NJ-Player-GUI.ps1  <- the GUI itself (PowerShell WinForms)

├── desktop-shortcut.ps1 <- "NJ Player" desktop icon (+ -Remove to undo)
├── make-icon.ps1        <- draws the NJ Player logo (nj-player.ico)

├── install.ps1        <- one-time setup (downloads mpv + shaders)
├── mpv.conf           <- core config + enhancement profiles
├── input.conf         <- extra hotkeys
├── scripts/
│   └── nj-presets.lua <- preset switching (F9, CTRL+0..3)

```

Everything is self-contained in this folder — you can move it anywhere (USB stick works) and it keeps working. To uninstall, delete the folder.

## Customizing

- **Change the enhancement strength** — edit `mpv.conf`: the `[nj-lucid]` and `[nj-cinema]` profiles list the shader files. Add or remove lines there. Shaders apply in the order listed.
- **Add shaders** — drop new `.glsl` files into `shaders/` and reference them from a profile in `mpv.conf`.
- **Start with enhancement on** — add `profile=nj-lucid` as the *first* line of `mpv.conf`. (mpv silently ignores a `profile=` line placed after the profile sections, so keep it at the top.)

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Video stutters on the Cinema preset | Your GPU is doing heavy upscaling. Use `CTRL+1` (Lucid) instead, or press `CTRL+h` to toggle hardware decoding |
| YouTube link won't play / "no audio or video" | Run `install.ps1` again so yt-dlp is present next to mpv.exe; check the link works in a browser first |
| Shaders not applying | Press `TAB` then `2` — you should see the pass names (e.g. "KrigBilateral"). If not, run `install.ps1` again to re-download the shaders |
| mpv.exe won't start ("DLL not found") | Install the Microsoft Visual C++ Redistributable, or switch to the MinGW build by editing the `$MpvUrl` line in `install.ps1` |
| Playback position not remembered | That's `save-position-on-quit` in `mpv.conf` — make sure the config wasn't modified |
| Video judders with interpolation | Edit `mpv.conf` and set `interpolation=no` (rare on modern displays) |
| Wrong volume (too quiet/loud) | Volume can go to 200% (`volume-max=200` in mpv.conf) |

## Update shaders or mpv

Re-run `install.ps1 -Force` to re-download everything.
